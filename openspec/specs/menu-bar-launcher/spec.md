## Purpose

菜单栏启动器让工具箱常驻 macOS 菜单栏并可通过全局快捷键瞬时唤起，使"随手用一下小工具"的成本降到最低，同时主窗口关闭后应用转入后台驻留而非退出。
## Requirements
### Requirement: 菜单栏常驻图标

应用 SHALL 在 macOS 菜单栏显示常驻图标，使用与 VS Code 风格莫比乌斯流线折带 V8 品牌一致的高清 18x18 Template 矢量剪影，支持左键切换窗口显隐、右键/Control-点击呼出快捷菜单（菜单至少包含"打开主窗口"与"退出"两项），并随深浅色模式自动适配对比度。当特定关键后台状态（如无人值守模式）开启时，菜单栏图标 SHALL 保持原生 V8 品牌 Logo 并呈现平滑呼吸律动动画，并在鼠标悬停时展示动态状态提示。

#### Scenario: 通过菜单栏打开主窗口
- **WHEN** 用户点击菜单栏图标并选择"打开主窗口"
- **THEN** 主窗口显示并置于前台（若已存在则聚焦而非新建）

#### Scenario: 通过菜单栏退出
- **WHEN** 用户点击菜单栏图标并选择"退出"
- **THEN** 应用完全退出，菜单栏图标消失

#### Scenario: 菜单栏图标视觉与主题自适应
- **WHEN** 用户在 macOS 深色或浅色模式下查看菜单栏
- **THEN** 托盘图标以高对比度单色 Template 渲染，轮廓清晰无模糊或边缘裁切失真

#### Scenario: 无人值守激活态动态呈现与呼吸动画
- **WHEN** 无人值守模式处于开启且有效状态
- **THEN** 托盘图标保持使用原生 V8 品牌单色模板图标（不替换主体 Logo），呈现柔和呼吸透明度脉冲动画，且悬停 Tooltip 包含无人值守运行状态与剩余时长信息。

#### Scenario: 无人值守停用或失效恢复默认态
- **WHEN** 无人值守模式被手动关闭或超时失效
- **THEN** 托盘动画立即停止，透明度恢复为 100% 常亮，Tooltip 恢复为默认提示。

### Requirement: 全局快捷键唤起

应用 SHALL 注册一个全局快捷键用于唤起/隐藏主窗口，即使用户正在其他应用中工作也生效。快捷键 MUST 可配置，并提供默认值。

#### Scenario: 从其他应用唤起

- **WHEN** 用户正在使用其他应用，按下全局快捷键
- **THEN** 主窗口立即显示并聚焦到搜索或上次使用的工具

#### Scenario: 再次按下隐藏

- **WHEN** 主窗口处于前台时用户再次按下全局快捷键
- **THEN** 主窗口隐藏，焦点返回之前的应用

#### Scenario: 快捷键冲突处理

- **WHEN** 默认或自定义快捷键被系统或其他应用占用导致注册失败
- **THEN** 应用提示用户快捷键不可用，并允许在设置中修改，不崩溃

### Requirement: 关闭窗口转为后台驻留

用户关闭主窗口时，应用 MUST NOT 退出进程，而是隐藏窗口并保留菜单栏图标驻留；仅通过菜单栏"退出"（或系统退出命令）才真正退出。

#### Scenario: 关闭按钮不退出

- **WHEN** 用户点击主窗口的红色关闭按钮
- **THEN** 窗口关闭，菜单栏图标仍在，通过全局快捷键可再次唤起且工具状态（如当前选中的工具页）按预期恢复
