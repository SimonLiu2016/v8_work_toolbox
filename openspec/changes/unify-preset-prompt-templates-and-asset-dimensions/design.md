## Context

当前短视频工坊预设库（`StudioPresetStore`）仅管理美学风格（`aesthetic_styles.json`）与时代题材（`visual_eras.json`），系统提示词与排版规则（三视图、纯净场景、道具展示、五维导演拆镜）均写死在 `prompt_assembler.dart` 与 `ai_constraint_engine.dart` 中；同时，场景图在生成时未传宽高，跌入 `ImageGenRequest` 的 `1080x1920` 默认竖屏参数；且角色提示词硬塞“修长挺拔”，与“矮壮微胖”冲突导致 AI 降维生成为幼童。具体背景参见 `proposal.md`。

## Goals / Non-Goals

**Goals:**
1. **统一工坊预设存储**：由 `StudioPresetStore` 统一纳管提示词模板资产（`prompt_templates.json`），实现出厂自愈、增量补齐、用户覆写与恢复出厂；
2. **可视化管理界面**：在 `StudioPresetManagementDialog` 扩展「系统提示词与规则」Tab，提供分类导航、富文本编辑与一键重置；
3. **全年龄阶段动态自适应（纯中文）**：基于中文语义与自然语言提取年龄阶层（幼童、少年、青年、中年、老年），注入对应骨骼身量约束，解绑死板的“修长挺拔”硬编码；
4. **场景图 16:9 宽屏纠偏**：场景图单视角与批量 7 方位生图默认绑定 `2K · 16:9` 宽画幅；
5. **IP 主库全局生图规格自由度**：封装统一的 `ImageDimensionSelector`，为三视图、场景视角、道具卡提供 1K~4K 与 16:9/9:16/1:1/4:3/21:9 的人工指定能力。

**Non-Goals:**
1. 不修改底层 AI 基础设施路由（`AiConfigStore`）及网络通信协议；
2. 不修改分镜视频合成与剪映导出逻辑；
3. 不破坏旧项目的本地 JSON 资产目录。

## Decisions

### 1. 扩容 `StudioPresetStore` 而非新建独立 Store
- **决策**：将 `prompt_templates.json` 放置在 `AppPaths.videoStudioPresetsDir` 下，由现有的 `StudioPresetStore` 统一负责加载、自愈、持久化与广播。
- **理由**：`StudioPresetStore` 已经成熟支撑了工坊在 `video_studio/global_library/presets/` 下的预设体系，具备完善的文件读写、版本自愈与防丢机制。新建 Store 会导致配置管理再次碎片化。
- **替代方案**：新建 `PromptTemplateManager` 或塞进 `SettingsStore`。被否决，因为前者制造配置孤岛，后者混淆了应用全局偏好与工坊领域资产的边界。

### 2. 采用原生纯中文自然语言提示词规范
- **决策**：提示词模板采用现代纯中文长句自然语言，对齐 Agnes 官方文档规范（`[主体] + [环境] + [风格] + [光照] + [构图]`）。
- **理由**：核对 Agnes 官方文档证实，其全部模型范例均为纯中文，具备极高的中文语义对齐与信息密度理解能力。过去引入的英文翻译不仅引入额外 token 开销，更极易将“少年”误译为幼童“young boy”。
- **替代方案**：继续保留中英双语强制翻译。被否决，因翻译模型经常遗漏微观体态，甚至导致词汇漂移。

### 3. 年龄阶段自适应与体态解绑架构
- **决策**：
  1. 解除 `CharacterTurnaroundProportion.standard` 对“身材修长挺拔匀称”的强制硬塞，替换为“写实人体结构，身长比例符合角色自身体型设定”；
  2. 建立纯中文年龄分级解析规则：
     - **幼童 (<13岁)**：保留童稚体态，稚嫩面容；
     - **少年 (13~18岁)**：显式注入“具备接近成人身量的半成熟骨架，骨骼正在拔高抽条，身材微胖但有少年身长，非低幼儿童，非幼童童子”；
     - **成年 (19~50岁)**：注入“成年骨骼完全成型，成熟挺拔身姿”；
     - **老年 (>50岁)**：注入“老年骨相，长者体态”。
- **理由**：彻底解决“修长挺拔”与“矮壮敦实”的死锁，消除将微胖少年绘制为年画福娃的先验偏置。

### 4. 封装 `StudioImageDimensionPreset` 与通用规格选择器
- **决策**：
  1. 定义数据结构 `StudioImageDimensionPreset`，枚举常见档位（1K / 2K / 3K / 4K）与比例（16:9 / 9:16 / 1:1 / 4:3 / 21:9），以及对应 Agnes 的标准原生分辨率；
  2. 场景图默认规格由隐式缺省改为显式声明 `2K · 16:9`；
  3. 封装轻量级下拉组件 `ImageDimensionSelector`，挂载在各资产卡生成栏。
- **理由**：直通映射 Agnes 官方尺寸参数，杜绝下游裁剪拉伸畸变，给创作者充分的主动权。

## Risks / Trade-offs

- **[Risk] 用户修改系统提示词后导致生图质量劣化或破坏排版** → **Mitigation**：在 UI 中明确标注每项模板的核心占位与约束目的，并提供醒目的「恢复出厂默认」按钮，随时可单项或全局一键复位。
- **[Risk] 旧版场景或历史配置未保存尺寸字段** → **Mitigation**：所有未指定尺寸的场景生图统一平滑回退到 16:9 默认值，历史已生成图片文件保持不变。
- **[Risk] 角色中文描述未写明具体年龄** → **Mitigation**：年龄解析器设置默认成年骨架兜底，仅当显式命中儿童词汇时才允许幼态特征。
