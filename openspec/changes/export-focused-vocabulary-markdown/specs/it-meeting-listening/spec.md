## ADDED Requirements

### Requirement: 重点关注词汇全量导出为本地 Markdown 文件
系统 MUST 支持用户将「词汇表」中标记为「⭐ 重点关注」的全部单词及其所属会议原句，全量导出为可读的 Markdown 文本并保存为本地 `.md` 文件。导出内容 MUST 包含以下信息：
- **元数据**：导出时间、重点词总量。
- **每个重点词**：展示词形（首次出现的原文形态）、音标（如已缓存）、词性（如已缓存）、中文释义（如已缓存）、全语料累计频次。
- **每个词的所属例句**：该词在全部真实会议中出现的不重复英文原句（`VocabularyPosting.sentence`），以及每条例句对应的中文翻译（如已生成）、来源会议材料名称、发言轮次与时间戳。

#### Scenario: 有重点词时导出完整 Markdown 文件
- **WHEN** 用户已标记若干词为「重点关注」，并在词汇表对话框中点击「导出重点词汇 (.md)」按钮，随后在系统文件保存面板中选择保存位置并确认
- **THEN** 系统在所选位置生成一个 Markdown 文件，内容包含导出时间、重点词总量、每个重点词的展示词形/音标/词性/中文释义/频次，以及该词在全部真实会议中出现的去重后的英文原句列表（含对应中文翻译与会议出处）
- **AND** 系统在界面给出保存成功的 SnackBar 提示，包含导出文件路径

#### Scenario: 无重点词时导出按钮禁用
- **WHEN** 用户尚未标记任何「重点关注」单词，词汇表对话框中显示「导出重点词汇 (.md)」按钮
- **THEN** 该按钮处于禁用置灰状态，点击无任何反应，并提示「先标记重点词汇」

#### Scenario: 同一原句重复出现时只导出一次
- **WHEN** 某个重点词在同一句原话中出现多次（例如 `Latency is latency`），该句被索引为多条出处记录
- **THEN** 导出的 Markdown 对该原句仅保留一条例句，不重复输出

#### Scenario: 部分助学字段缺失时平滑导出
- **WHEN** 某个重点词尚未缓存音标、词性或中文释义，或某条例句的中文翻译尚未生成
- **THEN** 系统仍正常导出该词与英文原句，缺失字段在 Markdown 中自然省略，不输出空占位符、`null` 或中断导出

### Requirement: 导出按钮与重点关注状态联动
系统 MUST 让「导出重点词汇 (.md)」按钮的操作状态与「⭐ 重点关注」词数实时联动，且导出操作不修改、不破坏任何现有重点词状态、助学数据或词汇索引。

#### Scenario: 标记新词后导出按钮立即可用
- **WHEN** 用户在词汇表中新增标记一个「重点关注」词，使 `focusedCount` 从 0 变为大于 0
- **THEN** 「导出重点词汇 (.md)」按钮从禁用置灰变为可点击

#### Scenario: 取消全部重点词后按钮回到禁用
- **WHEN** 用户取消最后一个「重点关注」词的标记，使 `focusedCount` 变为 0
- **THEN** 「导出重点词汇 (.md)」按钮回到禁用置灰状态

#### Scenario: 导出不影响现有数据
- **WHEN** 用户成功导出重点词汇 Markdown 文件
- **THEN** 词汇表中各词的「重点关注」状态、已生成的音标/释义/翻译缓存、以及词汇索引（`MeetingVocabularyIndex`）均保持不变
