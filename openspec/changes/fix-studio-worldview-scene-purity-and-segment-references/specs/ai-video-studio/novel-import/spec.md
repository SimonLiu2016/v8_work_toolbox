## ADDED Requirements

### Requirement: 小说场景资产纯净空间解构与硬约束

系统在通过大模型提炼长篇小说或单章小说的 IP 主库资产时，针对场景库（`scenes`）的提炼 Prompt 与校验 Schema，SHALL 显式施加纯空间物理环境硬约束：
1. `description_zh` 必须严格聚焦于空间建筑形制、室内陈设格局、材质纹理与环境主光/色温/天气，字数控制在 60 字以内；
2. 严禁包含任何具体人物（如“富家公子”、“江湖草莽”、“捕快”）、人物走动穿梭、对话或情节叙事动态；
3. `prompt_en` 必须输出适宜生图的英文环境空镜 Prompt，包含 `empty scene, no humans` 意图，严禁包含角色英文名或人类身份词。

#### Scenario: 小说解构提炼出纯净空镜场景
- **WHEN** 用户导入包含复杂人物交错、酒馆混战的小说文本
- **THEN** 系统提炼出的场景卡描述仅包含酒馆陈设、桌椅摆放与昏暗光影，不包含任何人物出场或交错叙事。
