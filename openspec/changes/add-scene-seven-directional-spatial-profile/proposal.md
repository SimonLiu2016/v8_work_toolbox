## Why

在小说解构生成 IP 主库的“场景”资产时，大模型默认生成的场景往往只有单一片段式的文学意境描述，缺乏立体的空间结构定义。这导致后续制作分镜与生图时：
1. 缺乏统一空间参照，不同镜头角度生图容易切镜穿帮、材质与光影自相矛盾；
2. 缺乏正反打、侧立面、天顶地坪以及鸟瞰全景的具体环境提示词，导致各镜头只能复用主正面，或者由生图模型随机脑补不同方位细节；
3. 用户在编辑场景时，无法对特定视角的空间陈设与视觉提示词进行针对性微调与按需单图/成套生图。

因此，需要在小说解构与场景资产库中引入「七方位空间全息档案」（前、后、左、右、上、下及俯视全景），既支持小说导入时自动推演补充，也支持场景库一键全量解构与单场景按需推导，且保持描述纯净、支持人工随时修改，并提供灵活的按需/成套生图控制。

## What Changes

- **场景七方位空间全息档案数据模型**：在 `SceneCard` 模型中扩展 7 个视角的空间视图映射（`front` 前/正面主景、`back` 后/反打背景、`left` 左侧立面、`right` 右侧立面、`top` 上/天顶结构、`bottom` 下/地面铺装、`topDown` 俯视全景），每个视角独立包含中文空间环境描述、英文生图 Prompt 与已生成的参考图路径。
- **AI 空间解构硬约束与推演引擎**：新增 `StudioAiTask.sceneSpatialDeconstruction`，结合世界观时代题材、建筑制式与小说基础描述，强制推演出 7 个方位纯净空间细节（严格禁止人物出镜与剧情叙事，确保跨方位材质与光源逻辑自洽）。
- **小说解构自动化与全案推演流程**：在小说全案导入与场景分析阶段，自动对提炼出的场景补充推演完整 7 方位空间描述与 Prompt。
- **场景库一键全息解构与按需推演**：在 IP 主库场景管理界面提供「一键全息解构全部场景」批处理功能，并在单场景编辑弹窗中提供单场景「AI 全息解构七方位」按钮。
- **多视角编辑与按需生图控制**：在场景卡编辑弹窗中呈现 7 方位网格编辑面板，所有方位的中文描述与英文 Prompt 支持自由编辑；支持单个方位点击「生成图片/绑定已有资产」，以及顶部「一键生成全息组图 (7视角)」按钮（不自动静默后台生图，保障配额可控）。
- **向下游分镜制作与镜头提示词匹配**：分镜生成与组装时，根据分镜的机位角度（如俯拍鸟瞰、仰拍天顶、正打/反打机位）优先匹配对应方位的空间描述与参考图。

### Modified Capabilities
- `ai-video-studio/series-asset-library`: 场景资产卡增加七方位空间全息档案（前、后、左、右、上、下、俯视全景）的存储、编辑与按需生图/组图生成支持。
- `ai-video-studio/novel-import`: 小说解构管线与批处理增加针对场景资产的七方位空间全息推演，自动补充 7 个方位的纯净空间环境描述与生图 Prompt。

## Impact

- **数据持久化与兼容性**：扩展 `SceneCard` 的 JSON 序列化与反序列化，旧剧集的 `SceneCard` 缺失七方位数据时平滑回退，保持向前向后完全兼容。
- **AI 约束引擎与 Prompt**：`ai_constraint_engine.dart` 增加七方位空间推演的 System Prompt、JSON Schema 校验与执行逻辑。
- **UI 与交互**：`series_page.dart` 场景列表顶栏增加一键解构入口，`_SceneEditorSheet` 重构为支持 7 方位卡片折叠/网格编辑、单独生图与一键 7 方位任务派发的交互面板。
- **下游编译链路**：`prompt_assembler.dart` 与分镜生图任务支持按镜头角度摄取对应方位场景描述与参考图。
