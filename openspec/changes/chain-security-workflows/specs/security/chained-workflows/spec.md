## Purpose

规范安全工具箱各核心功能模块（网络侦察、漏洞扫描、漏洞验证与利用、脚本生成、Security Agent）之间的跨视图导航、意图上下文传递及资产与漏洞动作下钻交互链条，消除功能孤岛。

## ADDED Requirements

### Requirement: 跨模块导航与上下文意图分发
系统 SHALL 在安全会话控制器中提供统一的跨模块导航与上下文分发机制，支持携带目标资产、开放端口/服务、漏洞发现（Finding）及预填参数在会话内的不同 Tab 间无缝切换，并在目标视图加载时自动消费上下文。

#### Scenario: 从资产触发跨模块导航并携带上下文
- **WHEN** 用户在资产卡片上选择“转入漏洞扫描”并指定目标资产 `192.168.1.50`
- **THEN** 主界面立即切换至“漏洞扫描”Tab，且携带包含该资产信息的导航意图对象

#### Scenario: 目标视图消费导航意图后状态自动清理
- **WHEN** 目标视图（如漏洞利用或漏洞扫描）成功读取并应用了导航意图中的目标参数
- **THEN** 系统控制器中的当前导航意图被重置消费，避免用户后续手动切换 Tab 时产生重复预填干扰

### Requirement: 侦察资产与开放端口动作下钻
系统 SHALL 在局域网侦察与 Web 侦察的资产列表与网络拓扑视图中，为每个发现的主机及其实际开放的服务端口提供结构化的动作下钻菜单（Action Menu）。

#### Scenario: 针对主机主体的快捷动作展开
- **WHEN** 用户点击主机卡片上的动作菜单
- **THEN** 菜单列出“一键漏洞扫描”、“转入漏洞利用”、“委托 Agent 深入评估”和“生成主机测试脚本”等可选项

#### Scenario: 针对特定端口服务的下钻操作
- **WHEN** 用户在主机详情中点击开放的特定端口（例如 `445/smb` 或 `80/http`）动作按钮
- **THEN** 系统支持直接以该端口服务为靶标，跳转到 Exploit 面板自动搜索相关服务模块或跳转到 ScriptGenerator 预填该服务的测试 Prompt

### Requirement: 漏洞发现项快速验证与处置入口
系统 SHALL 在 Nuclei 漏洞扫描结果列表和 Security Agent 发现物面板中的每个 `PentestFinding` 卡片上，提供标准化的验证、复测与处置快捷操作。

#### Scenario: 针对含 CVE 的 Finding 转入验证
- **WHEN** 用户点击某个包含 CVE 编号（例如 `CVE-2021-44228`）的 Finding 卡片上的“验证/利用”按钮
- **THEN** 系统切换至“漏洞利用”Tab，自动填入目标主机地址并在 PoC 搜索栏中填入该 CVE 编号

#### Scenario: 针对 Finding 一键生成验证脚本
- **WHEN** 用户点击 Finding 卡片上的“生成测试脚本”按钮
- **THEN** 系统切换至“脚本生成”Tab，将漏洞标题、目标地址及影响协议自动组装为脚本生成描述并填入输入框

### Requirement: Security Agent 推荐行动卡片与一键下钻
Security Agent 在完成自主渗透测试与分析评估后，SHALL 在建议报告底部根据审计结论动态渲染结构化的「推荐下一步行动（Actionable Next Steps）」卡片清单。

#### Scenario: Agent 报告渲染下一步行动建议
- **WHEN** Security Agent 完成执行并输出分析报告，识别出高危风险项或开放端口
- **THEN** 界面在综合建议下方以操作卡片形式展示具体的下一步动作（例如“复测高危服务”、“验证特定 CVE”、“生成加固方案”）

#### Scenario: 点击 Agent 推荐行动触发流程跳转
- **WHEN** 用户点击某条推荐行动卡片上的执行/转入按钮
- **THEN** 系统自动根据该建议携带对应的目标与动作参数，平滑切换至相应的工具面板并填入预设指令

### Requirement: 目标视图上下文自动消费与预填
各个安全工具视图（`VulnScanView`、`ExploitView`、`ScriptGeneratorView`、`SecurityAgentView`）在作为导航目的地激活时，SHALL 监听并消费控制器中的导航意图，自动填充对应的表单输入与筛选状态。

#### Scenario: 漏洞扫描面板自动高亮选中目标资产
- **WHEN** 用户携带资产 A 的意图跳转到“漏洞扫描”面板
- **THEN** 扫描目标勾选列表中自动选中资产 A

#### Scenario: 漏洞利用面板自动设置 RHOSTS 与搜索词
- **WHEN** 用户携带目标 IP 与服务或 CVE 信息的意图跳转到“漏洞利用”面板
- **THEN** RHOSTS 输入框自动填入目标 IP，搜索框自动填入指定服务或 CVE

#### Scenario: Security Agent 面板自动设置任务描述
- **WHEN** 用户从资产或端口选择“委托 Agent 深入评估”
- **THEN** Agent 面板的“描述渗透目标”输入框自动生成针对该目标与开放端口的精确任务描述
