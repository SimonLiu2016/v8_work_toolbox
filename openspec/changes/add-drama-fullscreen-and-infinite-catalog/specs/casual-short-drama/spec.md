# casual-short-drama 规约（增量）

## 需求与特性

### 桌面真全屏播放 (Native Desktop Fullscreen)
- **窗口全屏切换**：用户在播放器界面点击“全屏”按钮或按下键盘快捷键 `F` 时，必须调用 macOS 平台窗口通道使主窗口进入全屏模式；
- **全屏快捷退出**：全屏状态下按下 `Esc` 键、`F` 键或点击退出全屏按钮时，必须平滑退出全屏模式并恢复原有窗口尺寸；
- **纯净沉浸式视区**：进入全屏后，右侧选集抽屉自动折叠隐藏，视频居中呈现；鼠标闲置 3 秒后控制栏与标题栏自动淡出，鼠标移动时平滑浮现。

### 全库短剧探索与无限加载 (Catalog Infinite Scroll & All Filter)
- **「全部」全量大库入口**：分类选择栏首位提供「全部」入口（明确标识全量短剧总数，如 3300+ 部），展示上游全库聚合数据；
- **触底无限加载 (Infinite Scroll)**：在全宽短剧海报网格中向下滚动至底部附近时，自动异步请求下一页数据并平滑追加至网格末尾，无需手动翻页；
- **状态提示与边界控制**：
  - 正在加载下一页时，底部展示平滑的加载转圈指示；
  - 全部 3300+ 部短剧已加载完毕时，底部展示“已呈现全部短剧”的优雅提示；
  - 分页加载失败时提供“加载更多失败，点击重试”操作。
