## Purpose

提供短视频工坊（AI Video Studio）工作台外壳、响应式状态管理、顶部信息栏联动与运行引擎状态感知能力，保障连续短剧制作工作流的全局连贯性与直观反馈。

## ADDED Requirements

### Requirement: 顶部导航栏响应式联动与分集感知
The system SHALL 在用户切换剧集（Series）或切换分集（Episode）时，立即响应式刷新顶部状态栏的剧集名称、分集标题与制作类型标签，不得出现滞后或死锁。

#### Scenario: 切换剧集时顶部标题即时更新
- **WHEN** 用户在剧集库或其它面板选中另一部剧集
- **THEN** 顶部栏立即更新为所选剧集的名称和制作类型徽章

#### Scenario: 切换分集时顶部路径显示
- **WHEN** 用户选中了某剧集的特定分集（如第 2 集）
- **THEN** 顶部栏以面包屑形式显示「剧集名称 > 第 2 集: 分集标题」

### Requirement: 引擎运行状态明确指示
The system SHALL 在界面上显式标识当前图像生成与视频生成所采用的引擎档位（商业 API 模式 vs 本地免费演示模式），并在处于本地模式时提供快捷配置入口。

#### Scenario: 未配置商业 Key 时的本地演示模式提示
- **WHEN** 系统检测到尚未配置商业生图或生视频 API Key
- **THEN** 工作台提示当前处于本地免费模式（生成占位图与 Ken Burns 动效），并提供跳转至设置的快捷按钮
