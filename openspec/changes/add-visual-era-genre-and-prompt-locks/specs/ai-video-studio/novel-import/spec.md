## MODIFIED Requirements

### Requirement: 小说文本文件导入与长文解析

系统 SHALL 支持用户在创意孵化面板中导入本地文本文件（`.txt` 或 `.md` 格式），同时 SHALL 支持用户直接从「小说管理器」的小说库中浏览并选择整部小说或特定章节。导入或选择后，系统 SHALL 自动载入小说内容与元数据，通过大模型长文提取管线自动提取并结构化拆解出 IP 主库（世界观设定、时代题材标识 eraGenre、角色卡库、场景资产库以及短剧分集与前情钩子）。提取主要角色时，大模型 SHALL 依据识别到的时代题材补充完整的时代服饰细节与排他负向约束，杜绝缺失服装描写导致的现代概率污染。

#### Scenario: 成功导入小说并填充 IP 主库
- **WHEN** 用户在创意孵化面板选择并上传一部小说文本文件
- **THEN** 系统解析文本并自动生成世界观、识别匹配的时代题材标识（eraGenre）、主要角色卡（含中英文 Prompt 与时代服饰约束）、常驻场景卡及推荐的分集大纲，并自动持久化写入本地剧集存储目录

#### Scenario: 从小说库选择小说或章节导入剧集
- **WHEN** 用户在创意孵化面板点击“从小说库选择”，在小说弹窗中选中一部已有小说或勾选其部分章节并确认
- **THEN** 系统读取小说库中的标准化内容与背景设定，直接填充至剧集大纲提取上下文，生成匹配时代题材标识、角色卡、场景卡及分集大纲

#### Scenario: 导入无效或空文件
- **WHEN** 用户导入空文件或非纯文本内容
- **THEN** 系统展示明确的可操作错误提示并允许用户重新选择文件
