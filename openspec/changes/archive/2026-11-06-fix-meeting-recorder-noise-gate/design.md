## Context

参见 `proposal.md`。
经在本机 macOS 环境实测 MacBook Pro 麦克风数据，即使在安静房间不说话时，环境物理底噪（风扇、室内空气流动与拾音器增益）在 `astats` 测量下普遍位于 $-41\text{dB} \sim -32.8\text{dB}$。当前 `FfmpegMeetingRecordEngine.normalizeRmsDb` 将底噪标定为 $-52\text{dB}$，导致底噪被当成中等音量放大，输出高达 0.5~0.6 的电平。

## Goals / Non-Goals

**Goals:**
- 在不说话或室内环境物理底噪（$\le -31.0\text{dB}$）下，电平输出严格归零 `0.0`，所有波形柱平滑贴底为 3px 静态基线，不发生任何起伏与跳动。
- 在用户正常开口说话或大声发言时（通常处于 $-25\text{dB} \sim -10\text{dB}$），电平灵敏越过门限，并经非线性幂函数扩展至 50% ~ 100% 的动态范围，呈现富有张力的多频段波形起伏。
- 提供覆盖底噪边界（$-40\text{dB}, -35\text{dB}, -31.5\text{dB}, -31.0\text{dB}$ 归零）与有效发声区间的严格自动化单测。

**Non-Goals:**
- 不引入重型第三方 DSP 算法或深度学习音频降噪模型（如 RNNoise），保持极简高可靠。
- 不修改底层录音文件本身的音频数据流，仅优化前端 UI 声波可视化的电平感知与门限截断。

## Decisions

### 1. 静音噪门门限重标定：$[-31.0\text{dB}, -10.0\text{dB}]$ 结合 $t^{0.65}$

- **底噪门限 $minDb = -31.0\text{dB}$**：
  实测 MacBook Pro 麦克风室内安静时的最高峰值为 $-32.8\text{dB}$。将门限设定在 $-31.0\text{dB}$，可在完全过滤环境噪音的同时，对人声保持极高灵敏度。
- **人声上限 $maxDb = -10.0\text{dB}$**：
  常规说话（$-25\text{dB} \sim -18\text{dB}$）时，$t \approx 0.28 \sim 0.62$，经 $t^{0.65}$ 映射得到 $0.43 \sim 0.73$；大声说话（$\ge -12\text{dB}$）时输出 $0.95 \sim 1.0$。
- **归零截断**：
  当 $rmsDb \le minDb$、为 $null$、$NaN$ 或负无穷时，直接返回 `0.0`。

```
  输入分贝 (dB)           归一化比例 t               输出电平 level
 ─────────────────      ───────────────────       ───────────────────
  <= -31.0 dB            0.0                       0.0 (贴底静止)
  -25.0 dB (轻声)        (-25 - -31)/21 = 0.286    0.286^0.65 = 0.44
  -20.0 dB (普通)        (-20 - -31)/21 = 0.524    0.524^0.65 = 0.65
  -14.0 dB (洪亮)        (-14 - -31)/21 = 0.810    0.810^0.65 = 0.87
  >= -10.0 dB (大声)     1.0                       1.00 (满格爆发)
```

### 2. UI 层面平滑落底控制

在 `LiveWaveformMeter` 中：
- 当 `clampedLevel <= 0.001` 时，判定为静音/底噪状态，柱条统一渲染为 3px 静态基线；
- 配合已有的 `AnimatedContainer(duration: 65ms, curve: Curves.easeOutCubic)`，在说话停止时波形柱以平滑、舒适的曲线迅速平息收拢，杜绝生硬闪烁。

## Risks / Trade-offs

- **[极轻微耳语可能落入门限以下]** → 实测即使近距离压低声音耳语，麦克风电平也在 $-28\text{dB} \sim -25\text{dB}$，高过 $-31.0\text{dB}$ 门限，不会被误杀。
- **[不同麦克风硬件增益差异]** → 对于降噪麦克风（底噪约 $-60\text{dB}$），$-31.0\text{dB}$ 同样能完美工作且人声不受影响；对于高增益麦克风，$-31.0\text{dB}$ 能有效挡住大部分室内气流。
