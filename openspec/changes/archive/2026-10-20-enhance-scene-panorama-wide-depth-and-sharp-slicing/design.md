## Context

在之前的升级中，我们已经实现了 4K 全景母图生成（6272x2688）及 3D 沉浸漫游视口（`Panorama3dViewerDialog`）。但在实际业务场景中发现，切片机位依然存在明显的“贴脸逼仄”、“房梁与地面被切掉”、“画面发虚软糊”等体验缺陷。

经排查，核心矛盾在于：
1. **生图机位过近**：AI 缺乏“开阔大景深”约束，容易在室内墙壁附近建构空间；
2. **切片 FOV 偏窄**：默认 90° FOV 在 16:9 比例下垂直视野仅有 58.7°，有效容纳区域有限；
3. **像素抽取不充分**：90° FOV 仅抽取了母图约 1568 像素宽度，需数码放大至 1080P，导致纹理不锐利；
4. **插值高频衰减**：双线性插值重采样会损失瓦片与砖石的高频边缘。

## Goals / Non-Goals

**Goals:**
- **空间宏大完整**：提示词强制注入远景开阔大空间约束；切片默认升级至 105° 超广角电影画幅（垂直视野扩至 73.5°），横纵全貌尽收画幅。
- **细节极度锐利**：105° FOV 从 4K 母图提取 1830 像素物理宽度（几乎 1:1 点对点直出）；后处理加入轻量自适应边缘锐化（Unsharp Masking），彻底消灭发软发虚。
- **所见即切联动**：3D 漫游视口中创作者交互调整的视场角（FOV）与俯仰角（Pitch）支持同步存入 `SceneCard` 并作为四向切片基准。

**Non-Goals:**
- 不引入外部重型 Native / ONNX 神经网络超分依赖，坚守纯 Dart 本地微秒级图像处理与跨平台自洽。
- 不引入产生严重桶形弯曲的鱼眼畸变模型，坚守电影级直线透视（Rectilinear）投影。

## Decisions

### 1. 采用 105° 电影级超广角黄金视场
- **对比分析**：
  - 90° FOV：横向 90°（25% 覆盖），垂直 58.7°。在室内相当于特写拍摄，天花板与地面被腰斩；横向仅取 1568 像素，放大有软糊感。
  - 105° FOV：横向 105°（近 30% 覆盖），垂直 73.5°（高度视野提升 25%）。不仅能完整收纳横梁牌匾与地面，在 6272 宽母图下直接提取 **1830 像素**，输出 1080P 时接近 1:1 无损点对点映射！
  - 为什么不选 120°？在 Rectilinear 透视投影下，当 FOV > 110° 时，边缘拉伸形变急剧加剧；105° 是好莱坞宽银幕（16mm 等效全画幅）的最佳平衡点。

### 2. 轻量级边缘保留锐化增强滤波（Unsharp Masking）
- 在完成双线性球极透视重采样后，施加轻量卷积微锐化核：
  ```
  [  0, -0.25,   0 ]
  [ -0.25, 2.0, -0.25 ]
  [  0, -0.25,   0 ]
  ```
- 辅以对比度微调，消除双线性插值的模糊平滑效应，让石砖勾缝、飞檐瓦当与金漆雕花呈现影视级清脆质感。

### 3. 3D 漫游视角“所见即切”参数协议
- 在 `SceneCard` 中增加 `panoramaFov`（默认 105.0）与 `panoramaPitchOffset`（默认 0.0）持久化字段；
- `Panorama3dViewerDialog` 在点击“🎯 设为基准并切片”时，将当前视口的 Yaw、Pitch、FOV 完整返回；
- `series_page.dart` 将这组参数更新到场景元数据，并传给 `BatchSliceRequest` 触发批量重切。

## Risks / Trade-offs

- **过锐白边风险**：卷积核权重如果过大，会在高反差边缘（如屋檐接天处）产生白边。通过将增强系数限定在 0.25~0.30 之间的温和范围，既提升质感又避免边缘振铃（Ringing artifact）。
