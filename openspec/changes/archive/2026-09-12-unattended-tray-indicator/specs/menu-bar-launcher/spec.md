## MODIFIED Requirements

### Requirement: 菜单栏常驻图标

应用 SHALL 在 macOS 菜单栏显示常驻图标，使用与 VS Code 风格莫比乌斯流线折带 V8 品牌一致的高清 18x18 Template 矢量剪影，支持左键切换窗口显隐、右键/Control-点击呼出快捷菜单（菜单至少包含"打开主窗口"与"退出"两项），并随深浅色模式自动适配对比度。当特定关键后台状态（如无人值守模式）开启时，菜单栏图标 SHALL 保持原生 V8 品牌 Logo 并呈现平滑呼吸律动动画，并在鼠标悬停时展示动态状态提示。

#### Scenario: 通过菜单栏打开主窗口
- **WHEN** 用户点击菜单栏图标并选择"打开主窗口"
- **THEN** 主窗口显示并置于前台（若已存在则聚焦而非新建）

#### Scenario: 通过菜单栏退出
- **WHEN** 用户点击菜单栏图标并选择"退出"
- **THEN** 应用完全退出，菜单栏图标消失

#### Scenario: 菜单栏图标视觉与主题自适应
- **WHEN** 用户在 macOS 深色或浅色模式下查看菜单栏
- **THEN** 托盘图标以高对比度单色 Template 渲染，轮廓清晰无模糊或边缘裁切失真

#### Scenario: 无人值守激活态动态呈现与呼吸动画
- **WHEN** 无人值守模式处于开启且有效状态
- **THEN** 托盘图标保持使用原生 V8 品牌单色模板图标（不替换主体 Logo），呈现柔和呼吸透明度脉冲动画，且悬停 Tooltip 包含无人值守运行状态与剩余时长信息。

#### Scenario: 无人值守停用或失效恢复默认态
- **WHEN** 无人值守模式被手动关闭或超时失效
- **THEN** 托盘动画立即停止，透明度恢复为 100% 常亮，Tooltip 恢复为默认提示。
