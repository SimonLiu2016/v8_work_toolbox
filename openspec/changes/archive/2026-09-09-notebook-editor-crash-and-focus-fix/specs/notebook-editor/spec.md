## Purpose

定义笔记编辑器的国际化代理注入、生命周期状态隔离、持久焦点维持与全屏空白区点击捕获交互规范，确保笔记编辑过程稳定无异常。

## ADDED Requirements

### Requirement: 编辑器国际化代理支持
应用主窗口与所有子窗口的根 MaterialApp 必须注册 FlutterQuillLocalizations.delegate 国际化代理，防止富文本工具栏在创建与更新过程中因缺少 Localizations 抛出异常导致布局崩溃。

#### Scenario: 打开笔记窗口与工具栏初始化
- **WHEN** 用户点击打开记事本窗口或在笔记中切换
- **THEN** 富文本工具栏正常渲染各项按钮，无任何 Localizations 缺失异常或纯色色块降级占位

### Requirement: 编辑器组件状态与生命周期隔离
每个笔记编辑器必须根据当前选中笔记的 ID 绑定唯一的 Key，确保切换不同笔记时完整重置编辑器状态，防止在组件树内部提前释放未脱离引用的控制器。

#### Scenario: 在中间列表连续切换不同笔记
- **WHEN** 用户在第二栏笔记列表中连续点击切换不同的笔记条目
- **THEN** 右侧主窗口正确定位到目标笔记内容，不出现由于复用旧崩溃状态而导致的重复列或布局膨胀

### Requirement: 正文全屏空白区点击即聚焦
笔记正文编辑区域必须捕获用户在文本正文之外的空白区域点击事件，自动请求焦点并定位光标，保障新建空笔记时用户可即点即写。

#### Scenario: 点击新建空白笔记的正文空白区域
- **WHEN** 用户新建一篇空白笔记并在正文大片空白区域任意位置点击鼠标
- **THEN** 编辑器自动获取输入焦点并展示光标，用户键入的内容能立即呈现在笔记正文中
