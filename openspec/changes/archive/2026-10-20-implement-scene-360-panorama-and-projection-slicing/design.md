## Context

在目前的场景多视角工作流中，场景视角生成依赖串行调用 7 次图像生成 API。当生成反向视角（back）时，由于将正面图作为参考输入，受到 Agnes Image 2.5 Flash 底层图生图“强保留构图与主体布局”特性的限制，导致反打图与正面图雷同。

本设计引入 360° 等矩全景图（Equirectangular Panorama）生成，并在客户端实现纯数学虚拟相机切片投影（Spherical-to-Perspective），实现场景空间物理自洽、视角互补与资产提取。

## Goals / Non-Goals

**Goals:**
1. **全景 Prompt 构建器**：实现针对 360° 等矩球形全景图的专用文生图 Prompt 构建逻辑，严格遵守 Agnes 2.5 Flash 高信息密度规范，且禁止携带任何历史参考图以避免构图死锁。
2. **纯 Dart 虚拟相机切片投影引擎**：实现纯 Dart 算法模块（`SphericalPerspectiveSlicer`），通过逆向光线投射与双线性插值，将 21:9 / 2:1 等矩全景图投影切片为任意视场角（FOV 90°）、偏航角（Yaw: 0° 正面, 180° 反打, 90° 右视, 270° 左视）的无畸变透视图像。
3. **数据模型扩展**：在 `SceneCard` 中增加 `panoramaMasterPath` 字段，并在场景存储目录中创建 `panoramas/` 文件夹。
4. **场景资产编辑界面升级**：在 `series_page.dart` 的场景全息编辑界面中，新增【360° 空间全景母核】卡片、一键切片操作栏及切片状态显示，支持全景切片与独立重绘双模并存。
5. **Agnes 规格适配优化**：在 `resolveAgnesSizeAndRatio` 中精准支持超宽画幅比率（21:9，2K 分辨率 3136x1344），杜绝被错误回退映射到 16:9。

**Non-Goals:**
1. 不引入庞大的外部 3D 渲染引擎或 C++ 动态链接库，所有投影转换基于 Dart 纯数学与 `package:image` 内存位图运算。
2. 不破坏或重构现有分镜系统对 `SceneDirectionalView`（front, back, left, right 等）的既有机位指代协议，切片产物无缝兼容下游工作流。

## Decisions

### 1. 客户端纯数学光线投射切片 vs 服务端切片处理
- **选择**：纯 Dart 客户端算法运算。
- **原因**：切片投影属于确定性的几何坐标映射（逆向光线投射 + 双线性插值采样），在现代 PC 上切一张 1080P/2K 图仅需约 100ms。客户端切片实现 0 网络请求、0 流量传输、0 API 配额消耗，断网亦可重切机位。
- **替代方案**：通过 Python/后端微服务切片。缺点是增加依赖、网络传输延迟和运维复杂度。

### 2. 21:9 极坐标覆盖映射 vs 强制 2:1 补边
- **选择**：直接以 Agnes 原生支持的 `21:9`（2K: `3136x1344`）作为全景生成规格，投影算法按对应的实际角跨度（水平 360°，垂直约 154°）进行极坐标归一化。
- **原因**：Agnes 官方文档明确说明不支持原生 2:1，且精确尺寸会被自动重映射。21:9 在垂直方向覆盖了 $\pm 77^\circ$ 的仰俯角。影视电影水平分镜（视场角 FOV 90°，平视 Pitch 0°，微俯/微仰 $\pm 15^\circ$）完全落在有效采样区域内，避免了人为上下加黑边带来的像素污染和画质损失。
- **替代方案**：请求 2048x1024 强制 2:1。缺点是会被服务端标准化缩放到不可控的比例。

### 3. 全景母图生成时禁止注入参考图
- **选择**：生成全景母图时，显式将 `referenceImages` 置为空列表。
- **原因**：Agnes 2.5 Flash 官方文档指明图生图具有“构图保留”机制。为了获得物理自洽的 360° 闭环空间，必须利用文生图能力让模型在全新画布上绘制全息场景。
- **替代方案**：传入正面图做参考。已被证明会导致全景图只画正面朝向的内容，背向失真。

### 4. 界面交互：一键切片为主流程，保留单方位独立重绘
- **选择**：在场景编辑弹窗中，顶部增加“一键生成 360° 全景母图”与“一键无损切片全部分位”作为主流程；单个方位的 Tab 内保留“从全景重新切片”与“独立 AI 重绘”两个按钮。
- **原因**：既提供 1 次生图即可配齐全景 4 向机位的极致效率与绝对一致性，又给创作者针对特殊视角精细微调的自由度。

## Risks / Trade-offs

- **[Risk]** 大图（3136x1344）在 Dart 主线程中进行百万像素投影采样可能引起 UI 掉帧。
  - **Mitigation**: 使用 Flutter `compute` 将切片计算放到后台 Isolate 中执行，保证主线程 UI 60fps 流畅。
- **[Risk]** 某些特殊风格下模型未准确理解 360° 等矩投影，导致两极或接缝出现微小畸变。
  - **Mitigation**: 在 Prompt 头部注入强有力的等矩全景引导词（`360 degree equirectangular panorama projection`, `VR 360 spherical photosphere`），并在单个方位保留“独立 AI 重绘”以提供单点兜底。
