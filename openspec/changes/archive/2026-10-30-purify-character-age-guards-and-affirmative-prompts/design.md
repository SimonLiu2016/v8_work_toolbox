## Context

当前在“短视频工坊”中生成角色三视图时，像“余小白”（16岁矮壮白胖少年）这类角色频繁退化为 5~6 岁低幼童子。
根因分析详见 `proposal.md - Why`。核心技术约束在于：生图主力引擎 Agnes API 不支持 `negative_prompt`，系统组装在负向里的防低幼词库全被丢弃；而此前在正向提示词中加入的“非低幼儿童，非小娃娃，非低幼矮短”等否定句，在文生图大模型的注意力编码中触发了典型的“粉色大象悖论”，反而高权激活了低幼概念。加上角色卡拆分时“十五六岁”丢失，导致模型直接按“白胖圆润的小娃娃”出图。

## Goals / Non-Goals

**Goals:**
- 构建纯肯定式（Affirmative-Only）全年龄骨骼身量与体态比例规范，彻底根除正向提示词中的否定词句。
- 引入人体解剖学与测量学肯定表达，将口语化“矮胖”安全转译为青年敦实体格与舒展身长骨架。
- 实现角色关键年龄回溯机制（Age Inheritance），在容貌体态框缺漏年龄时自动从总述提取并强力置顶注入正向 Prompt。
- 强化小说全案解构（`novelMasterExtraction`）系统提示词，强制在拆解容貌体态时保留角色真实年龄。
- 升级 `StudioPresetStore` 出厂模板并提供安全过滤兜底。

**Non-Goals:**
- 不向 Agnes API 强行传递不支持的 `negative_prompt` 参数（避免引发 API 报错）。
- 不破坏现有已保存的角色卡数据结构，所有年龄回溯与置顶在生图拼装层无损自适应进行。

## Decisions

### 决策 1：纯肯定式正向骨骼身量模板重构（Affirmative Staging）
**方案**：彻底重构 `character_age_staging` 模板与代码 fallback：
- **少年（13~18岁）**：重构为：
  `具备接近成年男性的纵向骨骼身长，青少年身高（约165~170cm），骨骼充分拉伸，宽厚肩膀，成年男子头身比，面容青涩，男性下颌线条`。
- **体态解绑（矮壮/微胖）**：重构为：
  `标准写实体态比例，青年写实人体结构，身长比例符合矮壮敦实设定，体态丰满宽厚，拥有真实青年身长骨骼，四肢舒展`。
- **运行时去否定兜底**：在 `PromptAssembler` 装配最终正向提示词前，执行一层轻量级正向否定词清洗（自动剔除类似 `非低幼儿童`、`非小娃娃` 等历史残留）。

*替代方案考虑*：继续在正向里加强负面排斥词（如“绝对不是小孩子”）。已证伪：扩散模型无法理解逻辑非，强调越多，儿童特征激活越强。

### 决策 2：角色年龄回溯与置顶注入（Age Inheritance）
**方案**：在 `CharacterTurnaroundPrompt` 中新增年龄回溯提取器 `extractExplicitAgeAnchor`：
- 若 `facialFeaturesZh` 含有明确年龄（如“16岁”、“十六岁”），直接提炼；
- 若缺失，回溯角色的 `descriptionZh`（如“十五六岁左右的白胖少年”）；
- 提取后，转化为高权重的肯定式首置锚点（如 `16岁青年男性身量`），紧随三视图排版声明后立刻注入，确保注意力机制最先锁定青年骨架基调。

### 决策 3：小说主资产解构 System Prompt 强化
**方案**：在 `AiConstraintEngine.buildNovelMasterExtractionPrompt()` 中，修改 `facial_features_zh` 的提取指导：
- 显式声明：**必须完整保留原著中角色的明确年龄数字或人生阶段定语（例如“十六岁”、“二十岁出头”）**，严禁只提炼“白胖圆润”而遗失年龄主体。

### 决策 4：出厂模板自愈升级
**方案**：
- 更新 `studio_models.dart` 中 `StudioPromptTemplate` 的出厂预置内容为新版纯肯定句；
- 在 `StudioPresetStore` 加载时检测旧版包含“非低幼儿童”的默认模板，若用户未做个性化编辑则自动平滑升级为新版肯定规范。

## Risks / Trade-offs

- **[Risk] 用户自定义模板中依然包含“非低幼”等旧否定词**
  → **Mitigation**: 在 `PromptAssembler.build` 中加入正向提示词安全净化器 `sanitizePositiveAffirmative()`，即使模板里有否定词，在组装下发给生图引擎前也会被自动剔除。
- **[Risk] 角色总述中包含多个数字可能误判**
  → **Mitigation**: 年龄正则严格限定在 `(1[3-9]岁|十五六岁|...)` 等年龄特化模式，避免将“三层楼”、“两杯酒”等误判为年龄。
