## Context

当前实时声波组件存在两个核心问题：
1. **尺寸过窄**：固定为 16 根短柱（总宽约 130px，高 36px），无法利用中央录制卡片宽达 600~900px 的视窗空间。
2. **音量映射动态范围压缩**：采用线性分贝映射 $[-60\text{dB}, 0\text{dB}]$，笔记本麦克风拾取的常规人声能量通常在 $-38\text{dB} \sim -25\text{dB}$，线性计算得到的振幅值仅在 $0.35 \sim 0.58$。再乘以柱条权重后，实际渲染高度仅有 8~12px，导致肉眼感知“音波几乎没有波动”。

## Goals / Non-Goals

**Goals:**
- **感知增益优化**：将有效分贝区间收敛至麦克风人声敏感段 $[-52\text{dB}, -12\text{dB}]$，并采用非线性感知曲线（$\gamma = 0.6$），使日常交谈音量即可驱动波形达到 $60\% \sim 80\%$ 振幅，大声说话触及 $90\% \sim 100\%$。
- **宽展全屏适配**：`LiveWaveformMeter` 支持通过 `LayoutBuilder` 自适应铺满容器可用宽度，柱条数量增加至 36~48 根，高度提升至 64px。
- **生动的声波形态**：结合多峰谐波加权与实时动态散布，使整条声波呈现如同现代音频工作站（DAW）般灵动张弛的视觉效果。

**Non-Goals:**
- 不做高开销的 FFT 频域全分解，依然基于极低 CPU 占用的 RMS 能量流，通过多峰算法完成高拟真律动。

## Decisions

### 1. 分贝至振幅的非线性 Gamma 映射算法

- **区间重标定**：底噪阈值设为 $-52\text{dB}$（过滤环境静音与微弱杂音），人声峰值设为 $-12\text{dB}$。
- **归一化公式**：
  $$t = \text{clamp}\left(\frac{\text{dB} - (-52.0)}{-12.0 - (-52.0)}, 0.0, 1.0\right)$$
  $$\text{level} = t^{0.6}$$
- **效果对比**：
  - $-38\text{dB}$（轻声）：原输出 $0.36$ → 现输出 $0.53$
  - $-28\text{dB}$（正常说话）：原输出 $0.53$ → 现输出 $0.74$
  - $-18\text{dB}$（大声说话）：原输出 $0.70$ → 现输出 $0.91$
  说话时的波形高度将呈现极其显著的跃迁。

### 2. 宽屏自适应柱条布局（Adaptive Layout）

- 使用 `LayoutBuilder` 测量可用宽度，动态计算柱条数量（例如每个柱宽 4px + 间距 4px = 8px 单元宽度，在 400px 宽度下自适应渲染约 48 根柱条）。
- 柱条高度由 36px 提升至 64px，最大伸缩空间从 33px 扩大至 61px。
- 静音或未录音时，所有柱条保持 3px 基线圆角胶囊形态；一旦开始讲话，整面声波墙宽幅起伏。

### 3. 多峰谐波权重分布

- 40+ 根柱条不再采用单调平移，而是通过三峰正弦分布函数生成波峰波谷错落有致的天然声学轮廓。
- 配备颜色插值（低音量半透明 → 高音量亮色），形成高光呼吸质感。

## Risks / Trade-offs

- **[Risk] 宽屏下列数增多导致渲染压力** → 40~50 个柱条在 Flutter 现代化渲染引擎中渲染一帧耗时小于 0.2ms，使用 `AnimatedContainer` 或轻量 `CustomPainter` 均能维持稳定 60fps/120fps。
