## Why

在“编辑研讨室”中，当前界面在不足 200 像素的高内存在两处同名且紧邻的【重新规划本季大纲】按钮（篇章规格栏与分集小节标题栏），造成视觉与交互语义冗余混淆。
更严重的是，当导入长篇小说并采用推荐集数（通常为 60~100 集，默认 80 集）规划分集大纲时，AI Prompt 强制要求模型单次输出多达 80 个条目、包含 7 种复杂字段的超长完整 JSON，导致必然突破常规大模型 4096 输出 Token 限制被截断，进而导致 JSON 损毁与规划静默失败；而界面空状态缺乏就地错误反馈，造成“点击处理完依然是暂无分集数据”的卡死假象。

## What Changes

- **按钮层级精简**：移除小节标题 `🎬 全季分集规划与断章钩子` 右侧重复冗余的 `[重新规划本季大纲]` 按钮，将触发入口清晰统一在篇章规格栏（参数变更触发与主动重算）及分集空状态引导卡片中。
- **长篇大纲规划抗截断重构**：调整 `planWritersRoomSeasonBeats` 的 Prompt 约束，不再严禁截断或硬性索要 80~100 集单次完整 JSON，改为要求模型规划 4~6 大宏观篇章及 12~16 个核心高能转折节拍骨架，下游利用已验证的篇章感知平滑插值算法安全扩充至指定目标集数，彻底消灭 Token 截断导致的 JSON 损坏。
- **空状态内联失败诊断与重试**：在空状态卡片内增加规划失败状态与原因展示（如网络异常、模型服务不可用等），替代易被遮挡或快速消失的全局 SnackBar，赋予用户明确的就地诊断与重试入口。

## Capabilities

### Modified Capabilities
- `ai-video-studio/novel-import`: 规范编辑研讨室分集大纲规划的生成稳定性要求（防 Token 截断、平滑扩充机制）以及界面操作层级与空状态失败反馈。

## Impact

- `lib/tools/ai_video_studio/ui/writers_room_dialog.dart`: 精简标题栏冗余按钮，增加空状态卡片内联错误展示与重试交互。
- `lib/tools/ai_video_studio/services/ai_constraint_engine.dart`: 优化 `planWritersRoomSeasonBeats` 系统提示词与生成策略，确保在大集数（60~120 集）下稳定完成结构化解析。
- 相关单元测试与回归测试确保 100% 通过。
