## Why

当前笔记本主窗口中间列的笔记列表中，用户右键点击笔记卡片没有任何响应，缺少原生桌面笔记管理的核心快捷动作（如独立窗口查看、快捷方式置顶、快速添加任务、移动笔记本、附件另存、导出、复制链接等）。此外，笔记导出为 PDF 时由于默认字体缺乏中日韩（CJK）字形支持，导出的中文全部呈现为乱码，严重影响了文档的离线归档与打印分享体验。

## What Changes

1. **笔记列表右键上下文菜单（10项功能）**：
   - 为中间列笔记卡片增加右键监听（`InkWell.onSecondaryTapDown`），唤起 macOS 风格右键菜单：
     1. **新建笔记**：在当前选中的笔记本下快速创建空白笔记并聚焦标题；
     2. **在新窗口中打开笔记**：利用 `desktop_multi_window` 创建独立轻量窗口打开该单篇笔记，已打开则前置；
     3. **添加笔记到快捷方式 / 从快捷方式移除**：切换 `isPinned`，列表按置顶优先重新排序；
     4. **创建任务**：在当前笔记末尾插入一条待办复选框任务项（`- [ ] `）并落盘；
     5. **共享笔记…**：弹出共享面板（复制 Markdown、复制纯文本、另存离线 HTML）；
     6. **导出笔记…**：唤起导出格式与目录选择弹窗（PDF / Markdown / HTML / TXT）；
     7. **将附件保存到文件夹…**：扫描笔记附件与内嵌图片，另存至用户指定文件夹（保留原始文件名）；
     8. **复制笔记链接**：复制应用内深层链接（`v8work://notebook/note/{id}`）及 Markdown 格式链接；
     9. **移动笔记到…**：弹出笔记本选择器并将笔记迁移至目标笔记本；
     10. **删除笔记**：普通视图移至废纸篓并支持撤销，废纸篓视图确认后彻底粉碎。
2. **单篇笔记子窗口与跨窗口数据同步**：
   - 扩展子窗口参数协议支持 `note:<noteId>`，主窗口在重新获得焦点时刷新中间列，感知子窗口中的编辑。
3. **PDF 导出 CJK 中文字体保真**：
   - 改造 `ExportService._exportToPdf`，优先读取本地 macOS 系统中文字体（`/System/Library/Fonts/Supplemental/Arial Unicode.ttf`），离线零网络依赖；
   - 将 CJK 字体注入 `pw.Document` 全局主题，**并同时修正 `_exportToPdf` 中每处 inline `TextStyle`**（inline 样式优先于 theme base，仅注入主题不会生效）；
   - 字体对象按单例缓存，多次导出无需重复读盘。

### 明确移除（相较初版规划）

- **演示模式**：无分页策略设计，本轮不实现。
- **复制笔记到…** 与 **创建笔记副本**：完整克隆涉及附件路径改写，语义未定，本轮不实现。

## Capabilities

### Modified Capabilities

- `notebook-tool`: 扩展笔记列表交互规范，定义 10 项右键上下文菜单行为、单篇笔记子窗口与跨窗口刷新行为，并定义 PDF 导出时完整的 CJK 中文字体保真与渲染规范。

## Impact

- `lib/tools/notebook/ui/notebook_page.dart`: 中间列卡片右键触发、菜单构建、10 项动作处理器、共享/导出/笔记本选择/附件目录四个弹窗。
- `lib/tools/notebook/export_service.dart`: PDF 导出 CJK 字体加载与 inline 样式修正。
- `lib/tools/notebook/note_store.dart`: 附件提取工具方法（按原始文件名导出）。
- `lib/main.dart`: 扩展子窗口参数解析，支持 `note:<id>` 单篇笔记窗口；接入 `window_manager` 焦点监听。
