# Change Proposal: 听力练习解耦双维度控制（篇级三态循环模式与全场景句级跟读停顿） (add-dual-mode-playback-and-shadowing-controls)

## 1. 背景与问题陈述 (Context & Problem)
在“听力练习”模块中，用户普遍将“播放模式”理解为两个不同的维度：
1. **宏观维度（篇级流转）**：当前这篇素材（1~3 分钟）播完之后，是“播完即止”、“自动播放下一条（列表循环）”，还是“重复循环播放本篇（单曲循环）”？
2. **微观维度（句级跟读）**：音频播放过程中，句子之间是“自然流畅播放（畅听模式）”，还是“每句读完自动暂停留白（影子跟读模式）”？

由于历史上两套逻辑混杂在单一的循环开关和隐式状态中：
- 播放控制栏只有一个图标固定的循环按钮（`repeat_rounded`），点击后图标没有形状变化，悬停提示均带有“自动连播下一条”，用户误以为点击无效、无法切换到单曲播放或单篇循环；
- 句间自动停顿（跟读停顿）只在特定条件下暴露，公开素材库与会议场景体验割裂；
- 用户在需要暂停复述时难以开启，在需要连续单篇听完时又无法确信是否会跳转下一首。

## 2. 变更目标 (Objectives)
1. **解耦篇级循环与句级跟读**：在底层模型与控制器中将两者明确区分，避免状态混淆。
2. **支持篇级三态播放模式（LoopMode）**：
   - **单篇播放（orderOnce）**：当前素材播放完毕后立即停止，不切下一篇，留出思考复盘时间（默认）；
   - **列表连播（listLoop）**：当前素材播完后自动顺序播放下一段素材；
   - **单篇循环（singleLoop）**：当前素材播完后自动从头重放本篇，适合整篇精听。
   - 控制栏提供清晰的三态轮转按钮，图标彻底不同（`➡️` / `🔁` / `🔂`），附带明确的悬停 Tooltip 与即时 Toast 提示。
3. **支持全局通用的句级跟读切换（TurnMode）**：
   - 控制栏常驻直观的双态胶囊开关：`[💬 畅听模式]` ↔ `[⏸ 逐句跟读]`（高亮醒目）；
   - 无论处于公开素材库还是会议/排练场景，均可一键开启/关闭句间自动停顿。
4. **提升单测覆盖并完成本地部署交付**。
