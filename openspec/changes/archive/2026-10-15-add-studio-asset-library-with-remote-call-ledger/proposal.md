## Why

用户通过本软件发起的每一次云端生成都在计费，但产物与调用记录散落在三处、且互不相通：

1. **图片产物直接写进剧集目录**（`series_library/<剧集>/episodes/<集>/frames/shot_N.png`），没有任何独立标识。用户想把一张满意的关键帧用在另一部剧，只能去 Finder 里翻路径、手工复制。
2. **视频产物同理**，且它是异步任务——有 `video_id`、有云端 URL、可能失败可能超时。任务一旦从内存队列消失，用户既不知道它付过钱，也没有线索去云端取回。
3. **远端调用记录不落盘**。图片生成多数是同步接口、没有任务 ID，连"昨天用 Agnes 生成了什么"都查不到。

结果是：**用户为生成付了费，却既不拥有可复用的资产，也拿不回可追索的记录**。本次把两者补齐——本地精选资产进资产库并可被制作流程引用，远端调用记录永久保留并与本地资产关联。

## What Changes

### 1. 资产库（本地精选，可跨剧引用）

新增 `video_studio/global_library/images/` 与 `video_studio/global_library/clips/`，配一份 `asset_index.json` 索引。每条资产有稳定 ID（文件名即 ID），元数据记录来源（远端生成 / 本地导入）、供应商、模型、提示词、以及它最初的产出路径。

资产入库是**复制**而非移动——原剧集目录里的产物保持不动，资产是独立副本。资产的意义就在于它不依赖原剧存在。

资产库对制作流程开放两类引用：

- **图片资产 → 角色卡 / 场景卡参考图**：在角色卡与场景卡的编辑界面提供「从资产库选择」，选中即复制到该卡片目录并加入其参考图列表。复用既有参考图链路，不引入跨目录依赖。
- **视频资产 → 合成交付时间线**：合成面板新增「从资产库选择片段」来源，选中的片段按其在时间线的位置参与合成。不改动既有合成逻辑，只是多一个素材来源。

### 2. 云端调用记录（永久保留，可追索）

视频任务台账（`video_task_ledger`）从"任务追踪器"升级为"云端资产账本"：

- **永久保留已完成条目**。云端 URL 实测在任务完成后长期有效（`expires_at` 为 null，十分钟前完成的任务仍可下载），因此已完成任务的可追索窗口不受本地清理策略限制。失败与放弃条目仍按较短窗口清理。
- **补记远端调用**。图片生成虽是同步接口、无任务 ID，但调用本身（供应商、模型、提示词、产出路径、时间）落账，使用户可回望"我用哪个模型生成过什么"。
- **轻量刷新**。面板提供「刷新状态」——只查询一次、不重新挂起轮询。用户想看一个停在"云端处理中"的任务现在怎样了，不必重新等待一整段预算。
- **重新取回**。已完成任务的云端 URL 仍在时可重新下载；不在时明确告知，不静默失败。

### 3. 资产与记录的关联

资产索引记录它的来源调用；调用记录指向它的本地产物。关联是单向的——资产不知道自己被几个角色卡引用（那是卡片自己的参考图列表在记），调用记录也不知道产物是否被收进资产库（收进时在资产侧记来源即可）。

用户可从任一资产反查它的生成记录，也可从任一调用记录跳到它的产物。

## Capabilities

### New Capabilities

- `studio-asset-library`: 跨剧复用资产库——本地图片与视频精选资产的存储、标识、元数据、入库与按来源清理，及其在角色参考图与合成时间线两处的引用入口。

### Modified Capabilities

- `async-video-task-ledger`: 台账从任务追踪扩展为云端资产账本——已完成条目永久保留、补记无任务 ID 的远端调用、提供轻量刷新与重新取回、按终结性质区别清理。
- `ai-video-studio/shot-production`: 角色卡与场景卡的参考图选择新增资产库来源；关键帧产物可收进资产库。
- `ai-video-studio/segment-production`: 合成交付的素材来源新增资产库片段。

## Impact

**新增代码**
- `lib/tools/ai_video_studio/services/asset_library.dart`：资产索引的读写、ID 生成、复制入库、按来源查询。
- `lib/tools/ai_video_studio/services/asset_picker_dialog.dart`（或同等 UI）：资产选择器，供角色卡/场景卡与合成面板共用。
- 复用 `video_task_ledger.dart` 扩展调用记录，不新建第二套存储。

**修改代码**
- `lib/services/app_paths.dart`：新增 `videoStudioAssetImagesDir` / `videoStudioAssetClipsDir` / `videoStudioAssetIndexFile`，登记进 `allDirs` / `allFiles`。
- `lib/tools/ai_video_studio/ui/`：角色卡与场景卡编辑界面的「从资产库选择」入口；合成面板的资产片段来源；任务面板的云端账本区（刷新状态 / 重新取回 / 收进资产）。
- `lib/tools/ai_video_studio/services/studio_generation_tasks.dart`：关键帧生成完成后按用户意图入库（不自动入库）。

**数据**
- 新增 `asset_index.json`。既有剧集数据不变，无需迁移——资产库初建为空，用户按需填充。

**测试**
- 资产索引的增删查与原子写；资产入库为复制（原文件不动）；角色卡从资产库选图后参考图列表与文件均就位；合成面板能消费资产片段；调用记录补记图片生成、永久保留已完成、轻量刷新不挂轮询。

**非目标**
- 不做跨设备同步、不做云端资产库。
- 不做资产的标签/搜索/分类体系——初版只有来源元数据与列表，检索留给后续。
- 不改动角色卡与场景卡的数据模型（参考图仍是文件名列表，资产库经复制接入）。
