## Why

目前「短视频工坊」中存在关键的生图脱节与时代背景穿帮问题：
1. **生图链路遗漏风格锁与负向排他**：IP 主库中的角色三视图（`CharacterTurnaroundPrompt`）和道具图（`_PropEditorSheet`）完全没有拼接剧集的 `styleTokens`（风格锁），且缺少时代排他负向提示词；
2. **缺乏视觉时代与题材约束体系**：剧集只有一段自由文本的世界观（供人看，生图引擎不读取）与纯英文的 `styleTokens`。由于生图大模型（Flux/SDXL 等）缺乏服装下半身与时代锚点，在生成全身三视图时默认抽样现代服饰先验概率，导致仙侠/玄幻古装小说中的角色被生成为现代便服或沙滩裤；
3. **角色 Prompt 翻译缺乏上下文**：角色编辑弹窗中的「生成 Prompt」将制作类型写死为 `'drama'`（真人），且未传入剧集的世界观与题材背景。

引入「视觉时代与题材锁体系 (Visual Era & Genre System)」并打通 IP 主库全生图链路，能够彻底解决服饰穿帮与风格丢失问题，让古装、现代、科幻、废土、异世界等题材拥有精准、自动的服饰锚点与排他防御。

## What Changes

- **新增结构化题材与时代锁知识库 (`VisualEraGenre`)**：内置仙侠修真、古装武侠/穿越、现代都市豪门、科幻异能、末日废土、未来科幻/赛博、异世界奇幻等预设。每个题材定义中英双语标签、正向服饰锚点（如 Hanfu robes）、正向环境/材质锚点与强力排他负向违禁词（如排除沙滩裤、T恤、牛仔裤、现代手表等）。
- **剧集档案扩展题材字段**：在 `StudioSeries` 中新增 `eraGenre`（时代题材标识），向下兼容旧存档。
- **世界观设置界面升级**：在「IP 主库 → 世界观」面板顶部增加题材芯片选择器，用户可一键切换或自定义题材，实时展示生效的服饰锚点与排他词。
- **闭环修复角色三视图生图**：三视图提示词组装器全面接入题材服饰锁、全局风格锁以及多层负向排他词（三视图排他 + 制作类型排他 + 时代穿帮排他）。
- **闭环修复场景图与道具图生图**：道具图与场景图生图时均注入全局风格锁与对应题材的环境/材质锚点与排他负向词。
- **升级角色 Prompt 翻译引擎**：角色卡中点击「生成 Prompt」时，动态传入剧集真实的 `productionType`、`worldview` 及 `eraGenre`，使 AI 翻译生成的角色 Prompt 天然符合世界背景。
- **小说全案提炼自动识别题材**：小说导入第一阶段（Pass 1）大模型自动识别小说所属 `era_genre`，并在提取角色外貌与 Prompt 时补充符合时代题材的服饰细节。

## Capabilities

### Modified Capabilities
- `ai-video-studio/series-asset-library`: 在 IP 主库中为剧集增加时代题材锁（Visual Era Genre），包含服饰/环境正向锚点与排他负向词典；角色三视图、场景图、道具图生图及角色 Prompt 翻译均严格继承并应用全局风格锁与时代题材锁。
- `ai-video-studio/novel-import`: 小说全案第一阶段提炼（Pass 1）自动分析原著背景并输出匹配的 `era_genre`，在提取角色描述与英文 Prompt 时主动补充时代服饰与排他约束。

## Impact

- **数据模型**：`StudioSeries` 增加 `eraGenre` 字段，默认缺省兼容；
- **提示词组装服务**：`CharacterTurnaroundPrompt` 与 `PromptAssembler` 签名和生成管线升级；
- **AI 约束引擎**：`AiConstraintEngine.promptTranslation` 及小说提炼 Prompt 升级；
- **UI 页面**：`SeriesPage` 中的世界观面板、角色编辑弹窗、道具编辑面板、场景编辑面板联动改造；
- **测试覆盖**：更新并补充题材锁中英映射、三视图时代排他注入、小说提炼与道具生图的单元测试。
