# casual-short-drama 规约（标签与排序增量）

## 需求与特性

### 题材类型快速筛选 (Tag & Genre Filtering)
- **快捷题材选择栏**：片库界面提供热门题材横向选择栏（如 都市、现代、逆袭、重生、古风、仙侠、系统、职场、后宫、校园等）；
- **卡片标签即点即查**：短剧卡片上的题材标签必须支持鼠标点击，点击后立即以该标签为条件重刷列表；
- **重置与联动**：点击“全部题材”或清空搜索时，平滑退回全量片库。

### 多维排序控制 (Multi-criteria Sorting)
- **排序切换**：片库右上角提供排序切换（综合默认、评分最高 ★、集数最多）；
- **评分降序排列**：选择“评分最高”后，列表中的短剧严格按 `score` 从高到低排列（如 9.8 -> 9.7 -> 9.5...）；
- **分页追加保序**：当在特定排序规则下触底加载新数据时，新加载的短剧合并进集合后自动重新保持所选排序规则。
