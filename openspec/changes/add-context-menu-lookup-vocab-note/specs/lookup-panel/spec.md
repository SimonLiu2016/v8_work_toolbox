## Purpose

提供一个轻量级悬浮查词面板，用户可通过右键服务或全局热键触发，在任意应用场景下即时查询单词或翻译句子，并支持播放发音、添加至生词本、保存为笔记。

## ADDED Requirements

### Requirement: 查询结果展示

查词面板 SHALL 展示完整的词典查询结果，包括音标、词性、释义、例句和词组。

#### Scenario: 单词查询展示完整信息

- **WHEN** 用户查询一个英文单词
- **THEN** 面板展示该词的音标、至少一个词性分类、每个词性下的释义列表、例句（至少一条）以及相关词组

#### Scenario: 无词典结果时的 AI 翻译

- **WHEN** 用户查询的词在词典 API 中无法找到结果
- **THEN** 面板自动切换至 AI 翻译模式并展示翻译结果，同时显示「未在词典中找到」提示

#### Scenario: 长句自动切换 AI 翻译

- **WHEN** 用户查询的文字超过 3 个单词（以空格分隔）
- **THEN** 面板直接以 AI 翻译模式展示整句翻译，并提供「逐词查词典」入口

#### Scenario: 单词查询时提供 AI 分析入口

- **WHEN** 用户查询的是单词或短语（≤3 词）且词典结果已展示
- **THEN** 面板底部显示「问 AI」按钮，点击后可获取 AI 对该词在上下文中的额外解析

### Requirement: 发音播放

查词面板 SHALL 支持播放单词的真人发音（美式或英式）。

#### Scenario: 点击发音按钮播放音频

- **WHEN** 用户点击查词结果中的发音图标
- **THEN** 系统播放该单词的 MP3 发音音频

#### Scenario: 无发音资源时静默处理

- **WHEN** 词典 API 未返回发音链接或音频加载失败
- **THEN** 发音按钮显示为禁用状态，不显示错误提示

### Requirement: 浮窗行为

查词面板 SHALL 作为常驻置顶浮窗显示，点击面板外区域或按 Escape 键后自动关闭。

#### Scenario: 面板置顶显示

- **WHEN** 查词面板弹出
- **THEN** 面板始终显示在其他窗口之上，不被其他应用窗口遮挡

#### Scenario: 点击外部关闭面板

- **WHEN** 查词面板已显示且用户点击面板以外的区域
- **THEN** 面板自动关闭，不影响用户在其他应用中的操作

#### Scenario: 按 Escape 关闭面板

- **WHEN** 查词面板已显示且用户按下 Escape 键
- **THEN** 面板立即关闭

### Requirement: 一键添加生词本

查词面板 SHALL 提供「添加至生词本」按钮，点击后将当前查询词及其结果存入生词本。

#### Scenario: 添加单词至生词本

- **WHEN** 用户点击查词面板中的「添加至生词本」按钮
- **THEN** 当前词条（含音标、词性、释义、例句）被保存至生词本，按钮切换为「已添加」状态

#### Scenario: 重复添加已存在词条

- **WHEN** 用户查询一个已在生词本中的词并点击「添加至生词本」
- **THEN** 按钮直接显示「已在生词本」状态，不新增重复词条

### Requirement: 一键保存为笔记

查词面板 SHALL 提供「保存为笔记」按钮，将查询词及结果内容作为笔记保存至默认笔记本。

#### Scenario: 从查词面板保存笔记

- **WHEN** 用户点击查词面板中的「保存为笔记」按钮
- **THEN** 以查询词为标题、查询结果为正文，在默认笔记本中创建一条新笔记，面板显示保存成功提示
