## Purpose

提供独立的生词本工具，用于收集、管理和回顾用户在阅读中积累的英文单词和短语，支持结构化词条展示、标签管理、掌握程度标记，并可配置默认笔记本用于导出。

## ADDED Requirements

### Requirement: 词条存储与展示

生词本 SHALL 以结构化格式存储词条，每条词条包含单词/短语、音标、词性、释义、例句、词组、来源上下文、添加时间和掌握程度。

#### Scenario: 查看词条列表

- **WHEN** 用户打开生词本工具
- **THEN** 词条列表按添加时间倒序展示，每条显示单词/短语、词性缩写和掌握程度标识

#### Scenario: 查看词条详情

- **WHEN** 用户点击词条列表中的某一词条
- **THEN** 右侧详情面板展示该词条的完整信息：音标、发音播放、词性、释义、例句、词组和来源上下文

### Requirement: 手动添加词条

生词本 SHALL 支持用户手动输入单词或短语，触发词典查询后以查询结果预填词条表单，用户确认后保存。

#### Scenario: 手动查词并添加

- **WHEN** 用户点击「添加词条」按钮并输入单词
- **THEN** 系统查询词典 API 并将音标、词性、释义等字段预填至表单，用户可编辑后保存

#### Scenario: 手动添加无词典结果的词条

- **WHEN** 用户输入的单词/短语词典 API 无结果
- **THEN** 表单以空字段展示，用户可手动填写后保存

### Requirement: 从查词面板添加词条

生词本 SHALL 接受来自查词面板的一键添加请求，无需用户再次填写表单。

#### Scenario: 从查词面板快速添加

- **WHEN** 用户在查词面板点击「添加至生词本」
- **THEN** 词条及其音标、词性、释义、例句等信息自动保存至生词本，无需打开生词本工具

### Requirement: 删除词条

生词本 SHALL 支持用户删除单条词条或批量删除所选词条。

#### Scenario: 删除单条词条

- **WHEN** 用户在词条详情中点击「删除」并确认
- **THEN** 该词条从生词本中移除，列表更新

#### Scenario: 批量删除词条

- **WHEN** 用户勾选多条词条后点击「批量删除」并确认
- **THEN** 所选词条全部移除

### Requirement: 掌握程度标记

生词本 SHALL 支持用户对词条标记掌握程度（0–5 级），用于辅助复习决策。

#### Scenario: 修改掌握程度

- **WHEN** 用户在词条详情中调整掌握程度评级
- **THEN** 该词条的掌握程度字段更新，列表中的掌握程度标识同步刷新

### Requirement: 按标签和掌握程度筛选

生词本 SHALL 支持按标签和掌握程度对词条列表进行筛选。

#### Scenario: 按标签筛选

- **WHEN** 用户选中侧边栏中的某个标签
- **THEN** 词条列表只展示含有该标签的词条

#### Scenario: 按掌握程度筛选

- **WHEN** 用户通过筛选器选择掌握程度范围
- **THEN** 词条列表只显示在该范围内的词条

### Requirement: 配置默认笔记本

生词本工具 SHALL 在设置面板中提供「设为默认笔记本」功能，让用户指定词条导出或「保存为笔记」时的目标笔记本。

#### Scenario: 设置默认笔记本

- **WHEN** 用户在生词本设置中选择一个笔记本并点击「设为默认」
- **THEN** 该笔记本被标记为生词本的默认导出目标，后续「保存为笔记」操作使用此笔记本

#### Scenario: 未设置默认笔记本时提示配置

- **WHEN** 用户首次从查词面板点击「保存为笔记」且尚未配置默认笔记本
- **THEN** 系统弹出引导对话框提示用户选择一个默认笔记本
