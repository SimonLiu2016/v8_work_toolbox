## MODIFIED Requirements

### Requirement: 预设工作流按钮动态目标解析与本地流水线执行
用户点击一键预设工作流按钮（“Web 一键侦察”或“LAN 一键渗透”）时，系统 SHALL 动态从当前活跃会话中解析当前生效的目标（域名或网段），严禁使用组件构建时的陈旧闭包变量；且系统 SHALL 直接在本地启动确定性的原生工具流水线（Native Pipeline），严禁将包含目标域名与攻击性工具链的自然语言提示词发送给大模型进行工具调度。

#### Scenario: 切换会话后立即点击预设工作流
- **WHEN** 用户从包含 `baidu.com` 的会话切换到包含 `example.com` 的会话并立即点击“Web 一键侦察”
- **THEN** 系统动态以 `example.com` 作为目标，在本地直接调度启动 `subfinder → httpx → katana` 的原生流水线，严禁向云端大模型发送“全面评估 example.com 的 Web 安全”等指令

#### Scenario: 本地流水线执行中步骤与状态展示
- **WHEN** 本地流水线在执行过程中调用各个本地安全工具
- **THEN** Agent 面板中的“步骤与执行进度”卡片和“思考与操作日志”即时展示当前正在运行的工具名称与执行耗时，并在工具成功完成后打勾记录

## ADDED Requirements

### Requirement: 防御化与合规审计提示词体系
在本地流水线执行完成或用户主动发起综合分析时，系统 SHALL 以企业安全合规审计与系统防御加固视角构建 Prompt 并调用 AI，将已采集的结构化暴露面与漏洞数据作为输入，严禁使用引发大模型安全策略拒答的攻击性或未授权渗透测试词汇。

#### Scenario: 流水线完成后自动调用防御型 AI 分析
- **WHEN** “Web 一键侦察”或“LAN 一键渗透”本地流水线全部步骤执行完毕
- **THEN** 系统自动聚合当前会话的资产、开放端口与风险项，使用防御化合规架构师提示词请求 AI 生成“综合安全分析与防御建议”，确保主流商业大模型不触发安全拒答

#### Scenario: 用户在 Agent 输入框自定义输入
- **WHEN** 用户在“描述渗透目标”输入框中输入自定义提问并点击“启动 Agent”
- **THEN** 系统在系统提示词中强化防守合规与本地工具分析员约束，若大模型依然因敏感词拒绝执行，系统友好提示“云端策略受限”并引导使用本地确定性工具箱
