# Agnes 试炼场使用说明

「Agnes 试炼场」（`ToolCategory.ai`）是直连 Agnes 文本、图像、视频三通道的独立调试与归因工具。它独立于短视频工坊的具体剧集项目，支持自包含请求快照、脱敏请求视图与参数调优，供模型能力评估、提示词工程与实验复现。

---

## 1. 三通道直连能力

试炼场提供三个独立通道：

- **文本通道**：直连已配置的文本模型（如 `agnes-chat`、GPT 等），整段返回完整生成内容。
- **图像通道**：直连 Agnes 文生图/图生图模型，支持手填提示词、绑定多张参考图、选择 1K/2K/3K/4K 档位与 1:1、16:9、9:16 等画幅比例。
- **视频通道**：直连 `agnes-video-2.5` 与 `agnes-video-2.5-flash` 视频生成模型，支持完整参数微调与官方三种模式调度。

---

## 2. 视频生成模式与 `<Picture N>` 占位符写法

Agnes 官方视频生成支持三种互斥模式：

| 模式 | 适用场景 | 素材约束 | 占位符写法 |
| :--- | :--- | :--- | :--- |
| **首尾帧模式 (`keyframe`)** | 起始动作或首尾关键帧过渡 | 需提供**首帧**或**尾帧**（可仅传尾帧，或首尾齐备）；**严禁**携带参考图/参考素材 | 无需占位符，画面自然从首帧推进至尾帧 |
| **参考素材模式 (`reference`)** | 角色、风格、道具多图参考生成 | 需提供 **1~8 张参考图**；**严禁**携带首帧与尾帧 | 提示词中需使用 **`<Picture 1>`**、**`<Picture 2>`** 等占位符显式指代参考图编号（界面各缩略图下方有序号提示） |
| **文本模式 (`text`)** | 纯文生视频 | **严禁**携带任何图片或媒体素材 | 纯自然语言描述分镜画面、运镜与动作 |

> [!IMPORTANT]
> 试炼场在提交前会强制执行官方互斥规则校验。若在首尾帧模式下添加了普通参考图，系统将在本地直接拦截并说明原因，避免浪费 API 调用与积分。

---

## 3. 生成参数与规整说明

- **时长 (`durationSec`)**：支持 4s、5s、6s、8s、10s、12s。
- **清晰度档位 (`sizeTier`)**：
  - `agnes-video-2.5`：支持 `720P`、`1080P`、`1K`、`2K`；
  - `agnes-video-2.5-flash`：官方固定 `720P`。若请求其他档位，系统规整层将自动吸附为 `720P` 并在日志中留痕。
- **画幅比例 (`ratio`)**：支持官方白名单六种比例：`9:16`、`16:9`、`1:1`、`4:3`、`3:4`、`21:9`。
- **随机种子 (`seed`)**：可填入固定整数种子。填入相同种子与参数可在相同模型版本下最大程度复现画面实验。

---

## 4. 自包含快照与脱敏请求视图

每一次调用完成后，试炼场都会在 `video_studio/agnes_playground/turns/<turnId>/` 下生成一份完整且自包含的请求快照：
- 复制提交时引用的参考图本地副本（原图删除不影响快照回看）；
- 记录实际提交的提示词、吸附后真实参数、产物文件、耗时与任务 ID；
- 视频任务同步落入 `VideoTaskLedger` 台账，若本地轮询超时会自动标记为「云端仍在处理」，支持跨重启「继续等待」或复制 ID 追踪。

### 脱敏请求体视图 (`request_view.md`)
在消息气泡右上方可点击查看**脱敏请求体**：
- 系统会自动将庞大的 base64 Data URI 替换为一行易读的摘要信息（如 `<first_frame: 720×1280 JPEG 87KB>` 或 `<ref_1: 720×1280 JPEG 76KB>`）；
- 方便开发者与创作者直观复盘本次请求“实际向模型提交了什么”。
