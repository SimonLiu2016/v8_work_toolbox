# V8 工作工具箱 — 浏览器伴侣扩展 (V8 Browser Companion)

提供类似“豆包”的浏览器原生级划词查词与一键保存笔记能力。

## 特色
1. **一级右键菜单**：在网页任意选区中点击右键，直接在一级菜单展示「V8 工作工具箱」及其官方图标。
2. **快捷子菜单**：
   - **查词 — V8**：无缝呼起桌面端悬浮查词卡片（光标跟随，自动音标、例句解析）。
   - **保存笔记 — V8**：静默将当前选中文本及网页地址、标题直接存入 V8 笔记本。
3. **原生联动**：通过 `v8toolbox://` 原生系统协议直通桌面应用，零延迟且无需额外常驻后端。

## 安装指南（仅需 3 步）

1. 打开浏览器（Chrome / Edge / Brave / Arc）：
   - 在地址栏输入 `chrome://extensions/`（Edge 输入 `edge://extensions/`）并回车。
2. 开启右上角的 **「开发者模式」(Developer mode)**。
3. 点击左上角的 **「加载已解压的扩展程序」(Load unpacked)**，选择当前目录：
   ```
   /Users/simon/ClaudeWorkspace/V8WorkToolbox/extensions/v8-browser-companion
   ```

安装完成后，在任意网页中划选文字，点击右键即可体验！
